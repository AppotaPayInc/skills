# Bảng mã lỗi

> Phụ lục bảng mã lỗi

Các mã lỗi bôi đỏ cần gọi API kiểm tra giao dịch để xác định trạng thái cuối của giao dịch

| Mã Lỗi | Mô tả |
| --- | --- |
| 0 | Thành công |
| 1 | Thông tin yêu cầu thiếu hoặc không hợp lệ |
| 2 | Signature không hợp lệ |
| 11 | Partner không tồn tại |
| 12 | Số dư không đủ |
| 13 | Partner đã bị khoá |
| 14 | API Key không tồn tại |
| 23 | API Key chưa được kích hoạt hoặc đã bị khoá |
| 31 | Mã giao dịch bị trùng |
| 32 | Số tiền không hợp lệ |
| 33 | Giao dịch không thành công |
| 34 | Giao dịch đang được xử lý vui lòng kiểm tra lại sau |
| 35 | Giao dịch đang chờ xử lý vui lòng kiểm tra lại sau |
| 36 | Giao dịch không tồn tại |
| 40 | Hệ thống đang bảo trì, vui lòng thử lại sau |
| 41 | Nhà mạng ngừng hoạt động hoặc đang bảo trì |
| 91 | Hệ thống đang bận, vui lòng thử lại sau |
| 92 | IP không được phép truy cập |
| 99 | Lỗi không xác định, vui lòng kiểm tra lại giao dịch sau |
| 110 | Nhà cung cấp dịch vụ không tồn tại hoặc đang bảo trì |
| 112 | Dịch vụ không tồn tại hoặc đang bảo trì |
| 114 | Mã hoá đơn không đúng hoặc chưa đến hạn thanh toán |
| 115 | Hoá đơn đã hết hạn thanh toán |
| 116 | Hoá đơn không tồn tại |
| 117 | Số tiền thanh toán hoá đơn không hợp lệ |
| 118 | Hoá đơn đã được thanh toán |
| 119 | Dịch vụ đang bảo trì, vui lòng thử lại sau |
| 120 | Hoá đơn đã bị huỷ |
| 121 | Hoá đơn đã được xử lý |
| 122 | Không tìm thấy thông tin nợ cước của hoá đơn này |
| 123 | Truy vấn thông tin hoá đơn gặp lỗi, vui lòng thực hiện lại giao dịch |
| 124 | Thông tin hoá đơn không đúng |
| 130 | Không tìm thấy thông tin khách hàng |
| 131 | Số điện thoại chưa được hỗ trợ |
| 132 | Giao dịch đang được xử lý, quý khách vui lòng kiểm tra lại tài khoản hoặc liên hệ hotline 19006004 để được hỗ trợ |
| 133 | Giao dịch bị từ chối |
| 500 | Hệ thống gặp lỗi, vui lòng thử lại sau |
