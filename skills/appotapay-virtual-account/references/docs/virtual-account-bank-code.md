# Bảng mã ngân hàng

> Phụ lục bảng mã ngân hàng thu hộ

## Bảng mã

| Mã ngân hàng | Chi nhánh | Tên ngân hàng |
| --- | --- | --- |
| VIETCAPITALBANK | Chi nhánh Hà Nội | Ngân hàng TMCP Bản Việt |
| PVBANK | Chi nhánh TTGD Hội sở | Ngân hàng TMCP Đại Chúng Việt Nam |
| MARITIMEBANK | Chi nhánh Cầu Giấy | Ngân hàng thương mại cổ phần Hàng hải Việt Nam |
| WOORIBANK | Chi nhánh Hoàn Kiếm | Ngân hàng Wooribank |
