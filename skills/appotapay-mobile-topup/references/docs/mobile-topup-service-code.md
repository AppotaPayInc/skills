# Bảng mã nhà mạng

## Bảng mã nhà mạng

> Phụ lục bảng mã nhà mạng

| Mã Telco | Tên nhà mạng |  |
| --- | --- | --- |
| common | Nạp tiền điện thoại | Chi tiết |
| viettel | Nhà mạng Viettel | Chi tiết |
| vinaphone | Nhà mạng Vinaphone | Chi tiết |
| mobifone | Nhà mạng Mobifone | Chi tiết |
| vnmobile | Nhà mạng Việt Nam Mobile | Chi tiết |
| itel | Nhà mạng Itel | Chi tiết |
| gtel (beeline) | Nhà mạng Gtel | Chi tiết |
| viettel_data | Nạp data mạng Viettel | Chi tiết |
| vinaphone_data | Nạp data mạng Vinaphone | Chi tiết |
| mobifone_data | Nạp data mạng Mobifone | Chi tiết |

Chú ý:

- Với các đầu số 0592 (nhà mạng Gtel) thì sẽ sử dụng gói topup của nhà mạng vinaphone
- Với đầu số 0993, 0994, 0995, 0996, 0997, 0593, 0598, 0599(nhà mạng Gtel) thì sẽ sử dụng gói topup của nhà mạng mobifone
- Với đầu số 087( nhà mạng iTel) thì sẽ sử dụng gói topup với các mã code của nhà mạng vinaphone
