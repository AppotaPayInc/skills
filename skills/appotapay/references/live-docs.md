# Live docs — the source of truth (read before generating integration code)

The `references/docs/*.md` files in these skills are an **offline snapshot** of
https://docs.appotapay.com, generated by the tooling described here. They can lag the live site.

**Rule:** before you finalize endpoints, field names, codes, amounts, or base URLs in generated code,
**fetch the live page** and reconcile. If the live doc and a snapshot disagree, **the live doc wins**.

## The docs site has no machine-readable export

`docs.appotapay.com` is a Docusaurus site. There is **no `llms.txt`, no `llms-*-full.txt`, and no
OpenAPI file** — those paths all return 404. (Earlier versions of these skills pointed at
`llms-v2.0-<slug>-full.txt`; that scheme no longer exists.)

What the site does publish:

| Want | URL |
|---|---|
| Every page on the site | `{DOCS}/sitemap.xml` |
| One page (HTML) | `{DOCS}/<path>` — e.g. `{DOCS}/payment/signature` |

```
DOCS = https://docs.appotapay.com
```
> Working against a dev mirror (e.g. `https://docs.dev.appotapay.com`)? Set `DOCS` accordingly —
> the paths are identical.

## Versions

Paths with **no version prefix** are the current version. Archived versions are prefixed:
`1.1/<path>` and `1.0/<path>`. The snapshot ships the current version only; pass `--archived` to
the sync script if you need the old ones.

## How to fetch

Bundled helper — no dependencies, Node >= 18:

```bash
# every doc path on the site
node skills/appotapay/scripts/fetch-doc.mjs index

# only paths containing "subscription"
node skills/appotapay/scripts/fetch-doc.mjs index subscription

# one page, converted to Markdown (tables, code blocks and headings preserved)
node skills/appotapay/scripts/fetch-doc.mjs payment/signature
node skills/appotapay/scripts/fetch-doc.mjs ewallet/request-payment

# raw HTML instead
node skills/appotapay/scripts/fetch-doc.mjs --html payment/refund
```

Plain curl works too, but you get HTML:

```bash
curl -fsSL https://docs.appotapay.com/sitemap.xml
curl -fsSL https://docs.appotapay.com/payment/signature
```

In an agent with a web-fetch / browse tool, just fetch `https://docs.appotapay.com/<path>`.

## Where each area's pages live

Pages are routed to the skill that owns the product area:

| Doc path prefix | Skill |
|---|---|
| `payment`, `payment/…` | `appotapay-payment` |
| `merchant-hosted/…` | `appotapay-merchant-hosted` |
| `cc-merchant-host/…` | `appotapay-credit-card` |
| `ewallet/…` | `appotapay-ewallet` |
| `subscription/…` | `appotapay-subscription` |
| `virtual-account/…` | `appotapay-virtual-account` |
| `firm-banking/…` | `appotapay-firm-banking` |
| `bill/…` | `appotapay-bill` |
| `mobile-topup`, `mobile-topup/…` | `appotapay-mobile-topup` |
| `buy-card/…` | `appotapay-buy-card` |
| `charging-card/…` | `appotapay-charging-card` |
| `pos/…` | `appotapay-pos` |
| `authentication`, `security` | `appotapay-auth` |
| `errors`, `partner/…` | `appotapay` (this skill) |

Snapshot filename = the doc path with `/` replaced by `-`, under `references/docs/`.
So `subscription/create-plan` → `skills/appotapay-subscription/references/docs/subscription-create-plan.md`.

## Keeping the offline snapshot fresh (maintainers)

```bash
node skills/appotapay/scripts/sync-references.mjs              # current version
node skills/appotapay/scripts/sync-references.mjs --archived   # include 1.1/ and 1.0/
```

It discovers pages from `sitemap.xml`, converts each to Markdown, wipes and rewrites every
`references/docs/` directory, and prints a per-skill page count. A page whose path matches no
prefix in the script's `OWNERS` table is reported as an orphan — add the prefix (and, if it is a
new product area, a new skill) rather than letting it drop. Review `git diff` before committing.
